How it works

    

      

        
1 · Tokenizer

        
One left-to-right pass turns the text into tokens and validates the grammar. It even inserts the multiplication nobody typed: 2x → 2 · x, 3(4+5) → 3 · (4+5).

        
2 · Shunting-yard (Dijkstra)

        
Operands go straight to the output queue; operators wait on a stack and are popped when a lower-precedence operator arrives. Parentheses mark groups, functions pop after their arguments.

        
3 · Postfix evaluation

        
Pure stack machine: a number is pushed, an operator pops its operands and pushes the result. No parentheses, no precedence — that is exactly why postfix exists.

      

      

        
4 · Optimisation

        
The postfix program is parsed into an expression tree. Any subtree made only of literals is evaluated at compile time and replaced by a single constant. The shorter program is cached in an LRU cache keyed by source text, so re-evaluating skips lexing and parsing entirely.
