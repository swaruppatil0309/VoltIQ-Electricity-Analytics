# VoltIQ-Electricity-Analytics

Electricity Consumption Analytics using Probability, Statistics and Linear Regression.

This repository also hosts two complete **Data Structures & Algorithms projects in C++17**,
each with a compiled engine, an interactive visualiser and a single-file offline build.

---

## 🧮 VoltIQ Expr — Expression Solver &amp; Visualizer (C++ DSA project)

Infix → postfix conversion with a shunting-yard stack trace, postfix evaluation on a
stack machine, and compile-time optimisation (constant folding + an LRU program cache).

➡️ **Live demo: <https://swaruppatil0309.github.io/VoltIQ-Electricity-Analytics/>**
➡️ **Start here: [`ExpressionSolver/README.md`](ExpressionSolver/README.md)**

```bash
cd ExpressionSolver && ./run.sh      # builds the C++ engine + dashboard
./bin/xpr trace "2(3+4)^2 - sqrt(81)/3 + x"
open VoltIQ-Expr-Standalone.html     # or just double-click the single file
```

## 🏥 VoltIQ Care — Smart Hospital Management System (C++ DSA project)

This repository also hosts **VoltIQ Care**, a complete Data Structures & Algorithms
project in C++17: priority-queue emergency triage, hash-table + BST + binary-search
patient lookup, and sparse-matrix bed allocation — served by a compiled C++ engine
behind an interactive dashboard.

➡️ **Start here: [`SmartHospitalSystem/README.md`](SmartHospitalSystem/README.md)**

```bash
cd SmartHospitalSystem && ./run.sh      # builds the C++ engine + dashboard
```
